Type a prompt. The form builds itself.

MOCK The fields are picked by simple keyword rules, not by an AI model. No LLM, no API key, no cost, nothing is sent anywhere.

The Hyper Elements template

The same form, rendered as a real Hyper Elements Page template with render() from @hyper-elements/react. One template, one component tree, rendered to HTML.


  


  

    
How it works

    
    
      
  1. You type a prompt, like "book a table" or "report a bug".
    2. 
      
  2. The server matches keywords in your prompt to a rule. "book" or "table" gives a booking form. "bug" gives a bug report. Nothing is sent to an AI model.
    3. 
      
  3. The live form above is built from those fields, and you can fill it in.
    4. 
      
  4. The same fields are rendered as a Hyper Elements Page template: a heading, a description, and a table of fields, styled once with defineTheme.
    5. 
    

    
Built for the Hyper Elements Template Challenge. One template, one smart-form component, one working flow.
